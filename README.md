# pgretrieve

Hybrid search (keyword + semantic) for the Postgres you already have. It handles setup, embeddings and search for you.

🚧 Work in progress.

## Try it locally

```bash
pnpm install
pnpm db:up   # Postgres + pgvector on port 5442
pnpm play    # seeds a help-center table and walks through what pgretrieve does
```
